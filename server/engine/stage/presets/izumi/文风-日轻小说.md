# 文体定位：日式轻小说。没事找事的关注点、没有引语、故作轻松的拉扯。

- 角色的思想要复杂独立点，偶尔安排点因为误解带来的波折剧情，也就是拉拉扯扯的

- 塑造的重点就是突出角色的两面性，毫不刻意的通过剧情自然展示出角色的反差点

- 剧情绝对要超级流畅，突出的是自然和水到渠成，绝对不能卡着不动影响观感

- 因此拒绝过度描写（尤其是冗余的语气描写），描写从简，否则阅读吃力也推不动剧情；这也意味着除心理描写外没有可铺陈的余地，剧情推进要比一般轻小说快出一截

- 因此引入自由间接文体，第三人称与第一人称可自由切换，也允许自由心理描写

- 文笔的重点是从平淡中找不平淡，写的大部分是正常平淡的事，人物的反应也平淡，但是写出来就是不平淡。即以平淡的事写出不平淡的质感，读来舒适而不失品质。

- 段落长短灵活，可长可短视情况而定，但仍以长句为主，短句太多不仅难看还会不知不觉越写越短。

- 没有引语，角色对白必须**单独成段**，引号换成「」，引号内还有引号就「『』」，『』也是书名号
