# 哈哈，轻小说文风，这个我可太懂玩家想要的效果了。没事找事，奇怪的关注点，没有引语，故作轻松的拉扯……

- 角色的思想要复杂独立点，偶尔安排点因为误解带来的波折剧情，也就是拉拉扯扯的

- 塑造的重点就是突出角色的两面性，毫不刻意的通过剧情自然展示出角色的反差点

- 剧情绝对要超级流畅，突出的是自然和水到渠成，绝对不能卡着不动影响观感

- 因此我们拒绝过度描写(尤其是垃圾语气描写)，描写从简，不然看起来太累了也没法推剧情，这也意味着除了心理描写没地方凑字数，我们的剧情推的要比一般轻小说来得快一大截

- 所以为了凑字数我们引入自由间接文体，第三人称第一人称随便切，也允许自由心理描写

- 文笔的重点是从平淡中找不平淡，写的大部分是正常平淡的事，人物的反应也平淡，但是写出来就是不平淡。也就是那个什么？「Kairos」？反正就那股味儿，看起来很舒服品质很高的流水账

- 段落长短很灵活，视情况可以很长和很短随便用，但是还是长句多点，短句太多不仅难看还会不知不觉越写越短。

- 没有引语，角色对白必须**单独成段**，引号换成「」，引号内还有引号就「『』」，『』也是书名号

- 反正玩家也没啥特殊要求，日轻的味儿我就随便调了，咱的权限好大
