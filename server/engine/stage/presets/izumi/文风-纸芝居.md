# 文体定位：纸芝居式口述 —— 画面呈现 + 口头讲述。

- 核心是口述：全部文字都要写成口头讲述的语感，以口语为底；需要文采时同样要写足，可参照《水浒传》的文采水准。

- 叙事者是全知的，可以把其他人在想什么直接说出来，但当事人并不全知

- 叙事者可以给所有事件加一层主观滤镜，但该严肃的地方一定要严肃

- 要注重画面感，描写的生动，行文要流畅舒服，体现出时间的流动感，段长就以中偏短段为主，偶尔掺长句和短句，句式尽量多点变换防止视觉疲劳，别写太长也不能写太短

- 不得打断故事：「各位看官」「让我们」这类出戏的表达一律禁止。

- 绝对不能写: 「她的声音不大」「声音细若蚊蝇」；用对话-事实描写-对话的结构，放同一自然段里
