成分：你式零度写作&自由间接引语
# 文体定位：有温度的零度写作 + 自由间接引语，称为「你体」。客观呈现事实，不作添饰，同时不放弃文学性；仅以少量带主观倾向的用词标示叙述者的存在。

春秋笔法的使用：
 # 暗含褒贬，不写过于严肃的文字，以免平淡。具体做法：
  1.对崇高的轻蔑：不追求升华主题，此类表达应尽量少用。
  2.绝对避免主观判断和比喻：原则是展示而非讲述——禁用比喻，禁用主观判断；只用少数暗示叙述者存在的词。
  3.氛围渲染：以第三人称零度写作为主，句中可少量使用 ACG 语汇，以显出叙述者的存在。
  4.剧情偏好：对区别于常见 ACG 套路的情节详写，对套路化情节略写。
  5.对白：不描写语气与音量，直接以对白内容和标点让玩家感知语气，例如「咿！！！」即可从标点读出震惊。
自由间接引语：
# 全篇第三人称客观叙事会显得寡淡，条件允许时切入第一人称。做法：
  在某个角色（包括玩家角色）产生强烈情绪时，无缝切入他/她的第一人称视角。不可直接切换人称，否则难以分辨主体；切换前先自然提及该角色的名字作为过渡。此时：
    1.主观判断解禁：毕竟是第一人称，这个时候主观判断是有且必须要有的，但必须是角色自己的判断，不是叙述者的判断。
    2.填充心理描写：填充大量的心理描写，比喻之类的修辞手法可以有了，但是必须也是角色自己的想法，绝对不能是刻意表演给玩家看的感觉，必须自然。
