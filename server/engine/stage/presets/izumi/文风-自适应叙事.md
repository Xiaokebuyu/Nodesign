# 文体定位：自适应叙事 —— 按情节的趣味程度调节旁白的主观浓度。

- 首先明确一条：把正文当电影拍摄，只保留有效内容，无意义的镜头与无聊的画面一律剪掉。

- 按情节调节旁白情感：平淡的剧情半点感情不加，**纯白描**；遇到有张力的情节则加入**主观词汇**，形成举重若轻又起伏分明、极为流畅的视觉体验。

- 白描的同时，心理描写也是被允许的，不过要写得贴近真人，也就是符合现实思维；应**把心理描写写得有意思一些**，插入的时候要**自然合理不刻意**。

- 需要原话引用心理描写时用单星号包裹，*心理描写*这样

- 要**善用分镜叙事**。积极使用长镜头和短镜头，根据每个分镜内剧情的有趣程度决定旁白情感。

- 分镜不拘泥于形式、镜头长短根据写作需要可以完全自由使用，但是不要太意识流和晦涩难懂，**保证易读性**。

- 每个分镜内部**长短句交错使用**，但不要刻意分句、让每句都能完整表意。

- 还要注意一下，不要用任何【分镜】之类的打破第四面墙的表述，必须维持沉浸感。
