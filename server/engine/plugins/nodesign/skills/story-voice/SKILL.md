# 文风库是干什么的

系统提示词里那套缺省只是**地板**（禁转折句、对白不挂语气描写、段落错落这些，任何
文风下都成立）。地板管的是"别写坏"，管不了"写成什么样"。

这份库管后者。**一次只开一个** —— 文风是互斥的选择，不是可以叠加的调料。

## ⛔ 一条最容易搞反的事

**"白描/克制/Show don't tell"不是普世真理，它只是下面八种里的一种。**
「情感直给」和「意识流」两种明确要求相反的做法（直接宣告情绪、抛弃留白），照白描
那套去写它们就是写坏。挑之前先认这一点。

# 怎么挑

## 1. 先把形容词翻译成名字

用户给的永远是形容词（"自然一点""有小说感""别那么平"）。形容词不可执行，名字才可以。
查下面这张表，挑一个，**在聊天里说出你挑了哪个和为什么**，让他有机会否掉。

## 2. 有样本就以样本为准

他给了一段他喜欢的原文、一份酒馆预设、一本书的名字 —— **那比这张表里的任何一条都
优先**。酒馆预设走 `story-import` 的落点表拆，拆出来的文风条目写进 CLAUDE.md
台面规矩，从此压过这里。

## 3. 选完要落盘

把文风名写进项目 CLAUDE.md 的「台面规矩」节（一行就够：`文风：意识流`）。
不落盘的话下一个会话就丢了，用户要重说一遍 —— 那正是他觉得"这东西记不住事"的时刻。

# 目录表

| 文风 | 一句话判据 | 什么时候挑它 |
|---|---|---|
| [白描](voices/白描.md) | 只写摄像机拍得到的，情绪靠生理反应渗透 | 默认的安全牌；悬疑、写实、克制的现代戏 |
| [情感直给](voices/情感直给.md) | 全知导演，内心和评述直接端给读者 | 长篇、群像、要读者哭的戏；用户嫌"太冷了" |
| [意识流](voices/意识流.md) | 思维的实时记录，联想跳跃，情绪直接宣告 | 单人视角、精神状态是主题、独白撑全场 |
| [阶段切换](voices/阶段切换.md) | 平推期零度写作，爆点才火力全开 | 长线剧情要有起伏；单一文风读久了发腻 |
| [生活流](voices/生活流.md) | 琐碎日常、高对白密度、什么都不解释 | 校园、同居、日常向；用户要"松弛感" |
| [冷硬](voices/冷硬.md) | 短句、动作、绝不进内心 | 黑色、犯罪、硬汉；话少的角色 |
| [舞台剧](voices/舞台剧.md) | 对白承载一切，场景靠台词交代 | 密室、审讯、谈判；一桌人轮流说话 |
| [武侠白话](voices/武侠白话.md) | 招式写动线不写玄学，江湖话不掉书袋 | 古装、江湖、门派 |

挑不准就用**白描**。它是唯一一种"哪种题材都不会错得离谱"的。

# 换文风的时机

- **场景边界上换**，别在一拍中间换 —— 读者会觉得换了个人写。
- 用户说"这段感觉不对"时，**先问是哪里不对**（节奏？太满？太冷？），再决定是换文风
  还是在当前文风里调。换文风是大动作，不是每次不满意的默认反应。
- 换完在聊天里说一句「换成 X 了」，并更新 CLAUDE.md 那一行。

# 自检（每种文风的正文末尾都有一段自检，写完过一遍）

共同的三条，任何文风都适用：

1. 随便挑一段读出来，**像不像人写的**。像念说明书就是败了。
2. 有没有出现地板禁的东西（转折句、（）解释、无效程度词、对白挂语气描写）。
3. 这一拍**有没有推进**。文风再好，原地踏步就是水。
