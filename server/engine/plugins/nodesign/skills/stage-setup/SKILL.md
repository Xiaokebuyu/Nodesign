# 这一步在干什么

演戏的不是你。你负责搭台：把一场戏拆成**两种文件**，交给演出进程，然后退到场务位。
台上的每一拍由它写，用户的话直接进它的队列，不经过你。

| 文件 | 装什么 | 谁写 |
|---|---|---|
| `角色/<名>/角色卡.md` | **一个人的全部**：他是谁、怎么说话、绝不做什么、语气样本，加一块机器维护的"他记得的事"索引 | `cast_role`（用户在画布上也能改） |
| `stage/台面.md` | **这场戏的全部**：世界、难度、代笔档、文风、怎么演 | `open_stage` 的 `table` 参数（用户在显示器的「台面」按钮里也能改） |

演出进程的系统提示词 = 台面 + 在场每个人的卡（原文）+ 这场戏的记忆索引，别的什么都没有。
**人不进台面，世界不进卡**：八个人的戏写进八张卡就是八份世界副本，改一处漏七处；
反过来卡里只有人，这个人才能跟着卡跨项目搬。

改设定不用你重开：用户改了卡或台面，下一句话到时进程自己重开（他感知的只是那一句慢十秒）。
你改人设 = `cast_role` 重登同一个 id；你改规矩 = 再调一次 `open_stage`。

# 角色卡怎么写

`cast_role` 一人一张。persona 里写：他是谁、怎么说话、绝不做什么，**带两三句语气样本** ——
样本比形容词管用十倍。「她说话短，不解释自己」不如直接给一句「"我听见了。"」。
别把世界观塞进卡；一句话就过去的路人（端酒的店小二）不写卡。
判据：**有名字、还会再出现、用户会想单独跟他说话的**，写卡。

卡的末尾有一块 `nd:memory` 标记块，是机器维护的记忆索引 —— 你和用户都别碰它，
正文在 `角色/<名>/记忆/` 里，演出进程用 `remember` 带 `who` 往里写。

# 台面怎么写

按这个顺序写，别加节：

```
## 世界
时代、地点、这个世界跟现实差在哪。三五行，不写设定集。

## 台面规矩
难度档、代笔档、文风铁律、有没有骰子。用户在开场问答里选的东西全落这儿。

## 怎么演
每一拍走 write_scene；不可逆的变化用 remember 记一条（某个人记得的事带 who）；掷骰用 roll。
一拍别超过一屏。这场戏特有的口味写这儿：骰子用 d20 还是 d100、多久存一次档、
把手里那枚"意想不到"偏哪个方向。
```

# 冻什么，不冻什么

系统提示词是**冻结区**：它每一轮原样重发，命中缓存就几乎不要钱，一改就整份重付。

- ✅ 冻：世界、人物、规矩、文风。这些整场不变。
- ⛔ 别冻：当前时间地点、状态数值、这一拍轮到谁、刚触发的世界书条目。
  这些每轮都在变，写进系统层等于**每轮把整份提示词重付一遍**。

真账：酒馆四方世界卡实测每回合输入 75k-95k token 而**缓存读恒为 0**，一回合约 $1。
根因就是世界书按 order 插进上下文中部，让后面的内容整体位移，前缀永不复用。
我们这边同一场戏第二拍起整块命中（实测读回 12 万）。差别不在模型，在这一条纪律。

**⛔ 不要把项目 CLAUDE.md 塞进去。** 那是设计工作台的东西（构建命令、部署规矩、
代码约定），进了戏就是污染。演出要的设定全部写在这份提示词里。

# 一人分饰多角

台上所有人由一个会话写。这是定案，不派子代理。

最大的风险是**所有人一个腔**。防它不靠小心，靠两件事：

1. **每个反复出场的人在"人物"节里有自己的段落**，带语气样本。样本要写他真会说的话，
   不是描述他怎么说话。「她说话短，不解释自己」不如直接给一句「"我听见了。"」。
2. **每个人都有自己的卡**（`角色/<名>/角色卡.md`），开戏时整份进提示词，提示词里还留一句
   "开口前拿不准腔调就 Read 一遍他的卡"。演出进程有 Read，用户也能在画布上改那个文件。

判据：**有名字、还会再出现、用户会想单独跟他说话的**，写卡；一句话的过场自己带过。

# 上一场记住的事怎么接回来

**不用你贴。** 记忆有两个家，`open_stage` 交出去时机器都接上：
- **某个人记得的事**（态度、秘密、跟谁的关系）在他的卡上（`角色/<名>/记忆/` + 卡末尾的索引块），
  随卡整份进提示词 —— 这个人换一场戏、换一个项目还是他。
- **这场戏的事**（演到哪、伏笔、世界新事实）在 `stage/memory/`，索引接在提示词末尾。

都只贴索引不贴正文：索引一条一行、常驻很便宜；正文按需 Read，演出进程自己判断哪条用得上。
⛔ 别自己去读那些目录再摘要进台面 —— 那是上一场的演出进程留给自己的话，你摘一遍等于两份真相。

# 三件工具怎么教

演出进程手上只有这三件（外加 Read/Glob/Grep/Skill）。**基本用法机器会自动接在提示词
末尾**（「台面」一节：每拍 write_scene 带把手、不可逆的事 remember、掷骰 roll、不用
ToolSearch 找别的）。你在"怎么演"里只写这场戏特有的：多久存一次档、骰子用 d20 还是
d100、把手里那枚"意想不到"的口味。下面是三件工具各自的要点，写提示词时心里有数就行：

- **`write_scene`** —— 台上只认它写进去的东西。**正文之外不要再复述一遍剧情**，
  那会在画布和聊天里各出现一次。每次必须带 2-4 枚把手：一枚推进主线、一枚人际、
  一枚合理但意想不到的。**没有把手这一拍就没写完**。
  （真会话数据：342 条板书里只有 120 条带把手，35%。这是漏得最多的一条。）
- **`remember` / `forget`** —— 一事一份，形状照搬 harness 那套 auto-memory：
  frontmatter 里 `name` / `type` / `description`，正文写事实不写散文，
  写完索引自己重建。四类：`progress` 演到哪了、`character` 某个人的态度与他记得的事
  （**要带 `who`**，写进他的卡）、`thread` 伏笔、`world` 演出中确立的设定。
  **只在不可逆的事情发生时记**：关系变了、伏笔埋下或收回、世界里确立了新事实、
  玩家做了回不了头的选择。⛔ 别记这一拍的流水账，正文本身就在台上。
  同一件事再记就用同一个 `name` 覆盖，别新建第二份；剧情推翻了旧设定用 `forget` 删掉，
  别留两份打架的。
- **`roll`** —— 服务端真随机。⛔ 永远别自己编点数，编的会塌掉整桌的信任。


# 交出去：open_stage

卡都写好、开场三问问完，调 `open_stage` 一次：

| 参数 | 填什么 |
|---|---|
| `title` | 这场戏的名字，卡上和显示器顶栏都显示它 |
| `table` | 台面全文（上面那三节），写进 `stage/台面.md` |
| `cast` | 在场者 `[{name, note?}]`。**每个 name 都要已经有卡**，没卡它会拒开。一人 = 画立绘，多人 = 画名册；小字不给就用卡上的 note |
| `vitals` | 状态面板 `[{key, label?, as, max?, unit?, options?, initial?}]`。`as`：bar 进度条 / chips 几格亮一格 / num 数字 / text 一行字。演出进程在 write_scene 的 `state` 里按 key 更新。不需要面板就不传 |
| `skin` | paper 纸 / jiangnan 江南 / night 夜 / terminal 终端。按题材挑，用户随时能在窗里换 |

调完你就是**场务**：画布上多了一张演出卡，用户双击进显示器，他在那里说的每句话直接进
演出进程，不经过你。⛔ 之后别在对话里代演、别复述台上的剧情。他回到对话里跟你说话，
才是在跟你说话（改设定 / 换玩法 / 问怎么用）。

用户要"从头再来"让他自己删画布上那张卡（stage/ 文件夹），别替他删。角色卡不在 stage/ 里，删戏不删人。

# 开场先问清楚三件事

用 `AskUserQuestion` 一次问完，答案直接落进"台面规矩"节：

- **想跟谁演** —— 一对一 / 一群人 / 由你安排
- **难度** —— 爽（世界顺着他）/ 写实（他和普通人同权）/ 严酷（世界带恶意，
  但漂亮的输入该赢还是赢）
- **代笔到哪一步** —— 全代入（他的角色你一个字不代写）/ 大纲档（他给大意你扩写，
  但重要抉择必须停笔等他）

用户丢来酒馆卡或世界书时，先加载 `story-import`，落点表在那儿。
文风挑不准时加载 `story-voice`，剧情推不动时加载 `story-craft`。

# 写完自查

- [ ] 台面三节齐了，里面没有人物（人物在卡上）
- [ ] 每张卡都有语气样本，不是只有形容词
- [ ] 没有任何每轮会变的东西（时间、数值、当前场景）
- [ ] 没有项目 CLAUDE.md 的内容
- [ ] cast 里每个名字都有卡，且跟卡 frontmatter 的 name 一字不差
- [ ] 调了 open_stage，而不是自己在对话里开演
