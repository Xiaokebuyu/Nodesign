# 这一步在干什么

演戏的不是你。你负责搭台：把世界、人物、规矩写成一份**系统提示词**，交给演出进程，
然后退到场务位。台上的每一拍由它写，用户的话直接进它的队列，不经过你。

**这份提示词启动之后改不了**（SDK 没有 `setSystemPrompt`）。改人设 = 重开一场。
所以宁可先花两分钟问清楚，也别写一份撑不住的。

# 四节骨架

按这个顺序写，别加节，别改名。

```
## 世界
时代、地点、这个世界跟现实差在哪。三五行，不写设定集。

## 人物
每个会反复出场的人一段：他是谁、怎么说话、绝不做什么。
带两三句语气样本 —— 样本比形容词管用十倍。

## 台面规矩
难度档、代笔档、文风铁律、有没有骰子。用户在开场问答里选的东西全落这儿。

## 怎么演
每一拍走 write_scene；不可逆的变化用 remember 记一条；掷骰用 roll。
一拍别超过一屏。
```

# 冻什么，不冻什么

系统提示词是**冻结区**：它每一轮原样重发，命中缓存就几乎不要钱，一改就整份重付。

- ✅ 冻：世界、人物、规矩、文风。这些整场不变。
- ⛔ 别冻：当前时间地点、状态数值、这一拍轮到谁、刚触发的世界书条目。
  这些每轮都在变，写进系统层等于**每轮把整份提示词重付一遍**。

真账：酒馆四方世界卡实测每回合输入 75k-95k token 而**缓存读恒为 0**，一回合约 $1。
根因就是世界书按 order 插进上下文中部，让后面的内容整体位移，前缀永不复用。
我们这边同一场戏第二拍起整块命中（实测读回 12 万）。差别不在模型，在这一条纪律。

**⛔ 不要把项目 CLAUDE.md 塞进去。** 那是设计工作台的东西（构建命令、部署规矩、
代码约定），进了戏就是污染。演出要的设定全部写在这份提示词里。

# 一人分饰多角

台上所有人由一个会话写。这是定案，不派子代理。

最大的风险是**所有人一个腔**。防它不靠小心，靠两件事：

1. **每个反复出场的人在"人物"节里有自己的段落**，带语气样本。样本要写他真会说的话，
   不是描述他怎么说话。「她说话短，不解释自己」不如直接给一句「"我听见了。"」。
2. **人多了就把卡落到文件里**（`角色/<名>/角色卡.md`），提示词里只留一句
   "开口前先 Read 一遍他的卡"。演出进程有 Read，用户也能在画布上改那个文件。

判据：**有名字、还会再出现、用户会想单独跟他说话的**，写卡；一句话的过场自己带过。

# 上一场记住的事怎么接回来

开戏前读 `stage/memory/INDEX.md`，**整份贴进系统提示词末尾**，加一行标题和一句话：

```
## 这场戏记住的事
（INDEX.md 全文）

索引里的正文要用时自己 Read（在 stage/memory/ 下）。
```

⛔ **只贴索引，不贴正文。** 索引一条一行、常驻上下文很便宜；正文按需 Read，
演出进程自己判断哪条现在用得上。这也是索引里那句 description 存在的理由 ——
它是给"这条现在用不用得上"这个判断准备的，不是给人看的标题。

⛔ 别自己重写索引、别摘要 —— 那是上一场的演出进程留给自己的话。

# 三件工具怎么教

演出进程手上只有这三件（外加 Read/Glob/Grep/Skill）。教义就写这几句，别展开：

- **`write_scene`** —— 台上只认它写进去的东西。**正文之外不要再复述一遍剧情**，
  那会在画布和聊天里各出现一次。每次必须带 2-4 枚把手：一枚推进主线、一枚人际、
  一枚合理但意想不到的。**没有把手这一拍就没写完**。
  （真会话数据：342 条板书里只有 120 条带把手，35%。这是漏得最多的一条。）
- **`remember` / `forget`** —— 一事一份，形状照搬 harness 那套 auto-memory：
  frontmatter 里 `name` / `type` / `description`，正文写事实不写散文，
  写完索引自己重建。四类：`progress` 演到哪了、`character` 某个人的态度与他记得的事、
  `thread` 伏笔、`world` 演出中确立的设定。
  **只在不可逆的事情发生时记**：关系变了、伏笔埋下或收回、世界里确立了新事实、
  玩家做了回不了头的选择。⛔ 别记这一拍的流水账，正文本身就在台上。
  同一件事再记就用同一个 `name` 覆盖，别新建第二份；剧情推翻了旧设定用 `forget` 删掉，
  别留两份打架的。
- **`roll`** —— 服务端真随机。⛔ 永远别自己编点数，编的会塌掉整桌的信任。

再加一句"你的工具就这几件，不用 ToolSearch 去找别的" —— 不写这句它会白跑一趟搜索。

# 开场先问清楚三件事

用 `AskUserQuestion` 一次问完，答案直接落进"台面规矩"节：

- **想跟谁演** —— 一对一 / 一群人 / 由你安排
- **难度** —— 爽（世界顺着他）/ 写实（他和普通人同权）/ 严酷（世界带恶意，
  但漂亮的输入该赢还是赢）
- **代笔到哪一步** —— 全代入（他的角色你一个字不代写）/ 大纲档（他给大意你扩写，
  但重要抉择必须停笔等他）

用户丢来酒馆卡或世界书时，先加载 `story-import`，落点表在那儿。
文风挑不准时加载 `story-voice`，剧情推不动时加载 `story-craft`。
