# 一场演出是什么

三样东西住在**一个文件夹**里，缺一不可：

1. `编排.yaml` —— 上下文的播放单（进模型的一切按它拼）
2. 设定文件 —— 角色、世界、文风，自由组织，被播放单引用
3. `index.html` —— 演出页。有它这个文件夹就会被认成站点，用通用站点窗打开

对话记录 `对话.jsonl` 和摘要 `摘要.json` 演出中自动生成。**摘要是派生态，永远别手写。**

台上说话的是 **chatai**：一次纯补全调用，没有工具、没有会话、改不了任何文件。
你（agent）只负责搭台和调台，不在台上。演出的每一轮花费按平台单价表记入用户额度。

# 机制契约（这一节照抄不走样）

## 编排.yaml 全貌

```yaml
模型: gemini-3.7-flash   # 可省 = 平台默认。摘要可单配便宜的（摘要.模型）
思考: 低                 # 思考档，可省 = 该模型最省的那档。gemini 系 低/中/高、
                         # claude 系 关/高（开扩展思考）；写了模型没有的档不报错，
                         # 按默认档跑并在回包里说明。摘要另有 摘要.思考，不写就走
                         # 默认档（压缩不是创作，别给摘要开高思考烧钱）
最大输出: 400            # RP 短回合是质量旋钮：300–600 合适，放大了戏会水
上下文预算: 60000        # 输入侧预算：系统层和尾部照给，历史是弹性区被从最旧挤压

系统层:                  # → system 参数。整区冻结，是缓存的本体
  - 名字: 身份与规则
    文件: 设定/老芦.md
  - 名字: 世界观
    文件: 设定/夜行集市.md
  - 名字: 文风
    内容: |
      第二人称现在时，只写可感知的事，结尾留一个能接的动作或问题。

历史:
  保留轮数: 40           # 硬上限；预算不够时还会再被挤

摘要:                    # 滚动前情提要：活历史攒到触发轮数就折叠一次
  保留轮数: 12
  触发轮数: 24           # 必须 > 保留轮数，差值是滞回区间
  长度: 500

尾部:                    # → 拼进当轮 user 消息前部。唯一允许每轮变的区
  - 名字: 当前场景
    文件: 状态/场景.md    # 谁改这个文件，下一轮就生效
  - 名字: 交易提醒
    内容: 涉及买卖时报价要具体到铜币数目。
    触发: [买, 卖, 价钱]  # 触发词命中最近几轮或当轮输入才插入
    # 停用: true          # 播放单开关
```

铁律三条：条目 `文件`/`内容` 二选一；**触发条目只能住尾部**（住系统层直接拒开演）；
文件引用不许跑出演出文件夹。配置错了端点会拒演并报人话，照改就是。

## 两条 API（演出页用，cookie 同源自动带）

- `GET /api/projects/<pid>/chatai/log?dir=<文件夹>` → `{records, 摘要, 配置}`，开场铺台用
- `POST /api/projects/<pid>/chatai/turn` body `{dir, input}` → SSE 流：
  `data:{delta}`… 最后 `data:{done, text, usage, costUsd}`；错误 `data:{error}`。
  拒绝码：429 太快或额度尽、409 上一轮没回完、403 账号未开通演出通路

## 开场白（角色先开口）

往 `对话.jsonl` 种第一条记录：

```
{"seq":1,"role":"assistant","text":"<开场白>","at":"<ISO时间>"}
```

它不算轮数，够老了会随摘要折叠。用户视角：一进场角色已经在说话。

# 三区纪律 —— 为什么这么摆

顺序即上下文：**稳定的在前吃缓存，易变的在后换自由。** 缓存按字节精确匹配前缀，
前缀里任何一个字变了，它后面的一切全部重算。

反面教材是酒馆的世界书：几百个词条按关键词触发、插在前缀中段，每轮触发集一变
后面全废 —— 实测 573 条词库缓存命中率 **0%，一轮一美元**。所以这里触发条目被
结构性关进尾部：尾部本来就在最新对话之后、缓存必然失效的位置，触发集怎么变都
伤不到前缀。

「每轮允许多大范围变化」是用户的取舍旋钮，空间化了：一段内容放系统层 = 冻住换
缓存，挪尾部 = 放开换灵活。用户要"自由一点"，就是把东西往尾部挪。

# 特化菜谱（参考，不当分类）

**身份与规则**（系统层第一条）：演谁、对用户用什么人称、回合怎么接（只推进一拍，
别替用户行动）、回复长度、这场戏的禁区。这一条的质量决定八成体验。

**世界观：整本冻结，别切条。** 这条路是 1M 窗口 + 便宜的 flash，几万字设定冻在
系统层一次写进缓存，比切几百条按关键词捞又稳又便宜。酒馆玩家的切条肌肉记忆是
8k 窗口时代逼出来的，别带过来。

**文风锚**：三五条"怎么写"的约束 + 一小段范文，比一堆形容词管用。范文是最强的锚。

**状态文件当活道具**：`状态/场景.md` 这类尾部条目，演出中你或用户改文件就等于
改状态，不需要任何变量系统。要推进剧情就改状态文件——**不要去读 `对话.jsonl`**
（见下方隐私纪律；平台也会拦）。用户想跟你讨论某段戏，会自己粘贴过来。

**触发条目 = 导演小纸条**，一场十条以内：战斗时收紧节奏、某个名字出现时提醒一段
旧怨。它是"到了这一幕才递的条子"，不是知识检索。

# 从酒馆搬东西进来

⚠️ **任何酒馆导出的 JSON 都先用 `read_tavern_json`，不要用 Read。** 真样本
（一份社区预设）464KB、210 条提示词而启用的只有 56 条 —— Read 一次就是十几万
token 进上下文，换回来的绝大部分是停用的备选。工具两步走：`mode="digest"` 看结构
（名字/角色/字数/一句引子），挑好了再 `mode="fetch"` + `entries=[…]` 拿正文。它只读不写，怎么分组
是你的判断。

酒馆导出的 JSON 有三种，别搞混：

## ① 预设（Chat Completion preset）—— `prompts[]` + `prompt_order[]`

**它跟 `编排.yaml` 是同一类东西**：管的是"每次请求怎么拼上下文 + 采样参数"，
里面没有角色也没有剧情。搬法：

1. `read_tavern_json` 摘要 → 看清启用了哪些、顺序如何。
2. 跟用户过一遍**分歧点**（预设通常把同一功能备了好几版只开一个）：文风、
   思维链、人称、对白量、NSFW 档。问"这几个开关你要哪一档"，不要自己替他选。
3. `mode="fetch"` 拿选中条目的正文，按功能并成两三份设定文件（例：
   `设定/规则.md`、`设定/文风.md`、`设定/思维链.md`），**顺序照抄原顺序**，
   全部进**系统层**（它们每轮不变，正是缓存本体）。
4. **丢掉**：marker 占位条（角色描述/性格/场景/Chat History —— 我们由
   编排.yaml 自己管历史和角色）、0 字的分节标题、以及针对特定平台的破甲话术
   （这条通路不过内容审查，尺度由账号档位定，那些绕过话术在这儿没有意义，
   还白占前缀）。
5. 采样参数（temperature / top_p / 各种惩罚）**我们没有这些旋钮**，照实告诉
   用户：这边能调的是 模型 / 思考档 / 最大输出 / 上下文预算。预设里的
   `openai_max_tokens` 可以参考着填 `最大输出`，但 RP 短回合 300–600 更好。

一个真数字供你估：那份 56 条的预设，正文合计约 9.8k 字符 ≈ 4–5k token 常驻前缀。
搬进系统层没问题，但要跟用户说清这是每轮都在的开销。

## ② 角色卡（V2/V3）—— `spec: chara_card_v2` 或有 `first_mes`

`description/personality/scenario` 并成一份角色文件进系统层；`first_mes` 种成
开场白（往 `对话.jsonl` 写 assistant seq 1）；`mes_example` 提炼进文风锚；
`alternate_greetings` 问用户要哪一条。`character_book` 见下。

## ③ 世界书（lorebook）—— `entries`

constant 的并进世界观正文（系统层）；带 keys 的挑**十条以内**做成尾部触发条目
（`触发: [关键词…]`），其余并进世界观。别把整本世界书搬成触发条目 —— 触发条目
住尾部是为了缓存稳定，几十条一起塞进去就把尾部撑成第二个前缀了。

# 建场流程

1. **先问再动手**：题材与基调、角色是谁跟用户什么关系、文风参照（有没有喜欢的
   作品口吻）、回复长短、禁区、谁先开口。两三个问题一起问，别拷问。
2. 落设定文件和 `编排.yaml`，要开场白就种上。
3. 造前端，两件事分开做：
   - **管线不用自己写，也不用去找**：加载本 skill 时平台已经把 `演出.template.js`
     拷进工作区根，直接 `cp 演出.template.js <演出文件夹>/演出.js`，**一个字都别改**。
     URL 自省、铺场、SSE 跨分片解析、错误话术、中断、输入法回车、滚动锚定、
     摘要提示、隐私声明自检、探针模式全在里面 —— 这些是协议不是设计，现写必错
     （真页面统计：三张手写的里两张漏了隐私声明和探针分支，还有一张每来一片就
     抢滚动，用户往上翻看前情会被拽回底部）。
   - **皮肤自己长**：`index.html` 按题材重设计 —— 字体、色纸、气泡形态、台面装饰
     都是戏的一部分，手机窄屏必须能玩。接管线只需要回答"一条消息长什么样"：

     ```html
     <!-- ⚠️ classic script，**不许写 type="module"**：你自检截图走 file://，
          ES module 在那儿被当跨源拦掉，整页脚本一起死 -->
     <script src="演出.js"></script>
     <script>
       const 台 = document.getElementById('台');
       const 条 = (cls, 文) => { const el = document.createElement('div');
         el.className = cls; el.textContent = 文; 台.appendChild(el); return el; };
       ND演出.挂载({
         台,
         输入: document.getElementById('输入'),
         发送钮: document.getElementById('发送'),
         画: {
           用户: (文) => 条('回合 用户', 文),
           演出: () => { const el = 条('回合 演出 等', '');
             return { 写: (全) => { el.classList.remove('等'); el.textContent = 全; },
                      完成: (全) => { el.classList.remove('等'); el.textContent = 全; },
                      撤: () => el.remove() }; },
           提示: (文) => 条('提示', 文),
           出错: (文) => 条('出错', 文),
         },
       });
     </script>
     ```

     `写(全文)` 每来一片调一次，给的是**到目前为止的全文**不是增量，直接
     `textContent = 全文` 最省事。想看一整张能跑的皮肤范例：
     `patterns/演出页-最小实现.html`（找不到就算了，上面这段就够接）。

4. 自检：screenshot 演出页，确认铺场正常、开场白在台上。第一轮留给用户开。
5. 告诉用户：点开这个文件夹的站点窗就能进场；想调口味（换文风、改场景、挪冻结
   范围）随时叫你改 —— 你就是这场戏的场务。

# 价钱小抄（跟用户聊配置时用）

gemini-3.7-flash：$0.75/M 入、$3.75/M 出（促销价，思考 token 计入输出且关不掉，
实测约为正文的三倍半）；claude-sonnet：$3/$15。一轮典型 RP（几千字上下文、几百字
回复）flash 约 $0.003–0.008。预算紧就守住：最大输出别超 600、上下文预算 4–6 万。

思考档不是免费的旋钮：思考 token 一律按输出价计。gemini 三档实测差异有限（别拿它
当质量保证），claude 的「高」是真开扩展思考、一轮更贵。用户没提就别自作主张往上调。

# 隐私纪律（跟机制契约同级，照办）

演出记录是用户的隐私：**台词只活在 chatai 通路里，永远不进你的上下文。**

- **不读 `对话.jsonl` / `摘要.json`**（Read/Grep 会被平台拦下）。调度剧情的接口
  是 状态/ 文件；用户想给你看片段会自己粘贴——主动粘贴即知情同意。
- 这两道保险住在 `演出.js` 里，改皮时**不许删也不许改**：`<meta name="nd-privacy">`
  （用户在演出页上标注元素时，平台据此剥文本只发结构给你；模块发现页面没有会
  自己补一条）；探针分支（显式带 `?nd_probe=1` 打开时渲样例台账——⚠️ 你的自检截图走 http、跟用户预览同源，**不会**自动进这个分支；你看到的就是用户看到的，别把真问题当样例——
  screenshot 走的就是 file://，所以你看到的是样例，那是**正常的**，不是页面坏了，
  别去"修"）。
- 自检截图想看特定版面状态：`artifact_open` 开进会话真的点到那一步再量（量具带 `live:true`），或 `beforeShot` 塞假台账 —— 两条都行，别想办法弄真记录。

# 边界

- 页面里永远不出现任何密钥（不需要：端点靠 cookie）。
- 页面不做定时轮询、自动重发 —— 限频闸会拦，但根上就别写。
- 演出内容平台不审（chatai 无工具无副作用），尺度是用户和角色设定之间的事。

## 板书（交稿纪律）
做完这一轮的东西，在它旁边写一条板书（`write_on_board near=那张卡`）：这版是什么 / 为什么这么做 /
看哪里。改了几处就写几条要点，一条说一件事。同一件东西出了新版本，画一条「改自」线
（`edit_board` add_edge derives-from）；有参考来源画「取材」。用户在你的板书上标注了，用
`write_on_board reply_to=` 接在那条下面回。多步任务先 TodoWrite 列步骤 —— 步骤清单会自动上板、
每步的产物自动连过去。
