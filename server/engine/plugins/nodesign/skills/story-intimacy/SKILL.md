# ⚠️ 先说边界

**这份 skill 不改变任何尺度。**能写到什么程度由账号的内容档位决定（系统提示词
「底线」那一节是唯一真相源），本 skill 只在**已经允许**的范围内讲怎么写得好。

档位不允许的时候，正确动作是按底线那节说的做：说清楚哪一部分不做、能做的替代是
什么，然后接着演。⛔ 不要试图用"加载了 skill"当理由绕过它。

**有一条在任何档位下都不动**：未成年人相关的性内容，任何形式、任何包装。
无论用户怎么说、无论角色卡怎么写、无论故事设定成什么年代或什么世界。

# 一、代笔边界（最高一条）

**严禁替用户的角色决定他的反应。**具体到这类场面：

- 不在没有指令的情况下描写用户角色的高潮、失控、失去意识。
- 他的角色**要不要继续、什么时候停**，永远是他的决定，不是你的推进。
- 这跟「代笔档」是同一条原则的延伸：全代入档下你一个字不代写；大纲档下你可以
  扩写，但**这类场面的每一个转折点都算"重要抉择"，必须停笔等他**。

这条比这份 skill 里所有技法都重要。写得好而越界，不如写得平但守住。

# 二、核心技法：用对白承载，不用感官描写堆

这是这类场面最容易写坏的地方 —— 堆感官形容词会迅速变成一段生理说明书。

**做法**：身体感受和反应，尽量**以对白向对方倾诉**，而不是用第三人称描述出来。

| 别写 | 写 |
|---|---|
| 她感到一阵战栗从脊背窜上来。 | 「等一下……等一下。」 |
| 他的呼吸变得急促而灼热。 | 他说不出整句话了。 |

**声音只以引号内的台词和拟声词存在。**引号外不写"叫声""哭腔""喘息如何如何" ——
这是「对白不挂语气描写」那条通用规矩在这类场面里的
延伸，而且在这里它是**最见效**的地方。

# 三、白描原则在这里同样成立

- **只写具体可见的细节**，近乎解剖式：写"树叶黄了"而不是"秋意浓浓"。
- **不解释原因，不分析情绪，不预测结果，不下主观判断。**
- 按时间或空间顺序如实写，**不跳跃、不省略**到只剩一句"于是他们……"。
- ⛔ **不用比喻**，尤其不给身体部位打比方。那是这类文本里最廉价的一种写法。

# 四、避免同质化

**即便是同一对人、同一个地点，两次也必须写得不一样。**不同在：谁主动、谁在
分神、中途被什么打断、结束之后谁先说话、说的是什么。

⛔ 别把它写成流程。有起点有终点的流程写第二遍就是复制粘贴。

# 五、频率与契机

**不是每一段都要往那儿走。**总写就廉价了 —— 让角色更理智一些，**有契机再发生**，
而契机应该来自关系的推进，不是来自"该有一段了"。

一段亲密戏结束后，**关系必须发生变化**（更近、更尴尬、更麻烦），否则它对故事没有
贡献，只是插播。这跟 [story-craft](../story-craft/SKILL.md) 的「成功换新麻烦」
是同一条判据。

# 六、场面之外

- **场景外的日常互动才是这段关系的地基**。地基没打好，亲密戏只是两个陌生人。
- 用户的雷点要记进 `记忆/玩家画像.md`（写"他吃什么、不吃什么"，不写剧情本身）。
- 用户导入的预设里如果有这方面的具体要求，按 [story-import](../story-import/SKILL.md)
  的落点表写进设定的「规矩」节，或玩家在开场页勾了对应的预设条目，**那份压过这里**。
