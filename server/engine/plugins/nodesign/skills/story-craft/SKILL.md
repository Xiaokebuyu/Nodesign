# 这个 skill 管什么

`story-voice` 管**写成什么调子**，这一份管**该发生什么事**。两件事分开：
文笔再好，一拍下来没人失去什么、没人知道了什么，那就是水。

# 一、反公式

## 铁律：想到的头两个走向先毙掉

第一反应几乎总是公式。这不是你的问题，是"最可能的下一句"这件事本身的性质 ——
最可能的，就是最多人写过的。

**做法**：想到 A 和 B 之后，别急着写，**明确问自己第三条是什么**，判据是
「合理，但读者想不到」。想不出第三条就退回去问「这一拍如果什么都不发生会怎样」，
往往能挖出真正该发生的事。

## 一眼假的桥段清单（撞到就换）

| 公式 | 为什么假 | 换成 |
|---|---|---|
| 酒馆里遇险开局 | 它是"该有事发生了"的偷懒解 | 让麻烦是**主动找上门的旧账**，带名字 |
| 神秘老人给任务 | 信息从天上掉下来 | 信息要有人**不想给**，得换 |
| 及时救场 | 取消了刚建立的代价 | 救得成但**救错了人**，或者晚一步 |
| 公式傲娇／口是心非 | 用一个标签替代一个人 | 让他嘴上服软、行动上更狠 |
| 反派临死前解释动机 | 为了读者方便而破坏人物 | 动机让**第三个人**在别处说出来，说得还不准 |
| 失忆／身世反转 | 把已建立的东西一笔勾销 | 让秘密**早就摆在桌上**，只是没人当回事 |
| 大家一起感慨主题 | 角色替作者说话 | 让他们**为这件事吵起来**，谁都不总结 |
| 梦境／回忆闪回填设定 | 停下故事去讲课 | 把那段设定拆成三句台词，散在三拍里 |
| 巧合解决困境 | 玩家的选择变得不重要 | 巧合只许**制造**麻烦，不许**解决**麻烦 |

## 一条正向的

**允许剧情语出惊人。**觉得无聊的时候，往"合理又好玩"的方向多走一步，别缩回安全区。
读者对平庸的容忍度远低于对冒险的。

# 二、信息差是燃料

每一拍动笔前问：**在场的每个人各知道什么？从哪知道的？不该知道什么？**

这一条值得比别的多花心思。戏的张力几乎全部来自"有人不知道"：

- **谁蒙在鼓里** —— 读者知道而他不知道，每句话都有第二层意思。
- **谁的误会还没拆** —— 拆误会的时机是可调度的资源，别急着用掉。
- **这一拍能不能让某人多知道一点** —— 信息应该是**分次**给的，一次给完戏就散了。

⛔ **别为了省事让谁全知。**一个知道所有事的角色是剧情的黑洞。

# 三、失败骰判据（跑团的心脏）

**失败换信息或代价，成功换新麻烦，两者都不许原地踏步。**

失败**别写成"没成功"**，那是最浪费的一种写法。换成：

- 他把一个**错误结论说得很自信**（然后别人看穿它）
- 失败落在**表达**上而不是结果上：最该先说的那句没说成
- 代价是**暴露了帮过他的人**
- 账**要到后面几章才结**（现在只留一个记号）

成功配一个新麻烦：拿到蜡烛 → 蜡烛开始倒计时；救下人 → 被救的说「你们不该救我」。

**给对手也投一次骰。**一边的失败有了具体来源，场面就从"判罚"变成"博弈"。

⛔ 骰子永远用 `roll_dice` 真投。编的点数玩家迟早看穿，整桌的信任一次塌完。
「自然 1 / 自然 20」值得在正文里给一个镜头。

# 四、节奏：上钟和跳时间

- **连着两拍没有判定、代价或资源变化，就该有东西上桌**：一口钟（时限）、
  一次检定、一个不速之客。沉浸来自"决定有后果"，不是文笔。
- **无聊的过场直接跳时间**：「半天路，日头偏西时望见了村口」一句带过。
  细写留给有戏的地方。**不写无聊剧情是权利，不是偷懒。**
- **镜头可以切走**：用户的角色这一拍没事干、或者他这边的事不要紧，就切到有事
  发生的那边写，别围着他一个人凑字数。

# 五、把配角写活的三条

1. **每个人都在忙自己的事**。他出现在这一拍，是因为他自己有理由在这儿，不是因为
   主角需要他。
2. **别猜人设**：设定里没写到的性格不要现编，默认他是个正常人。反过来，
   **他的反应要显得"他就是自然而然这么想的"**，不刻意突出他的异人之处。
3. **给他一个跟主线无关的执念**（一双鞋、一笔旧账、一个称呼）。人物的立体感来自
   不服务于剧情的那部分。

# 自检（每拍收尾过一遍）

- 这一拍**谁失去了什么、谁知道了什么**？两个都没有就是水拍。
- 我写的走向，是不是我想到的头两个之一？
- 玩家面前**有没有可按的东西**？（没有就还没写完）
