当前的问题

为什么"AI 帮我做 PPT"还远远不够。
  • 每个项目都从零 brief 开始，设计意图没有持久化。
  • 下一次想用同样风格做新 deck —— skill 不记得你上次的选择。
  • skill 黑盒，效果不达标也不知道从哪里改起。

两种范式的对比

传统：单次手工艺

每次都重新构思 metaphor、重新选 palette、重新写 prompt。

设计决策散落在 chat 历史里，不可检索。

skill 是黑盒，不达标只能换 prompt 试运气。

Nodesign：基础设施

spec 持久化设计意图，跨 run 跨项目可复用。

HTML 产物 + 局部修改链路，所见即所得。

skill 是被工作台反向优化的对象，不是天花板。
