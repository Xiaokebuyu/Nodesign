2026-09-09桌面 0.1.32 → 0.1.34

一天三版，都是用的人报上来的

  • 界面缩放功能整个拿掉：Windows 显示缩放 110% 时输入框和浮动工具栏会溢出，问题出在缩放本身
  • 自带密钥可以用与内置同名的模型 id，不再报「已存在」
  • 首页项目栏混入别人公开的作品，自己项目越多混入越少
  • 板书太长时中间自动折起，头尾保持可见
  • 站点、Word、文件夹这些窗口给钉住的聊天卡让位
  • 白天模式卡片影子的锯齿修掉；桌面版更新改走国内可达的镜像
2026-09-08桌面 0.1.13 → 0.1.31

一天十九版

  • 市场 v2：作品可以直接发布上架，别人能「照着来一个」，agent 也能替你发
  • 打开本地文件夹当项目：agent 站在你的仓库里干活，画布只看它写下的东西
  • agent 的浏览器在桌面版里原生显示，它在看什么你看得见，随时能接手
  • 演示稿并入站点形态：海报、演示都是固定画幅的页面，不再单独问比例
  • Word 导出在 Windows 上修好（此前几版全线失败）
  • 模型：接入 DeepSeek 官方渠道，GLM-5.3-Flash 两条渠道，按会话自动换线
  • 桌面版内置诊断端点，出问题能让站主远程看日志
