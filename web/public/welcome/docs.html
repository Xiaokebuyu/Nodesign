入门

从小型任务开始

首次使用可选择小型任务。描述需求后，Agent 会确认信息并开始制作。

无需配置线上版本注册即用，无需配置模型。

桌面版安装后登录站点账号，或在设置页配置自有密钥（BYOK）。下载 Windows 版。

五分钟 从需求到第一件产物了解需求描述、Agent 响应和产物位置。 → 画布 拖动、圈选与关系线调整产物位置，圈选区域并连接产物关系。 → 计费 用量与费用查看每轮 token 与金额，了解免费模型和付费模型。 →
产物

同一块画布，四种产物

产物形态是画布对象的属性。Agent 按对应规范生成内容。

内容复用图像完成背景移除后可用于页面，Word 文档中的图像可用于演示。

网页 站点与落地页基于 HTML/CSS 构建，支持响应式布局、直接发布和整站导出。 → 文档 Word 文档与演示Word 文档符合中文排版规范，演示按屏翻页。 → 图像 图像与视频支持图像生成、背景移除、海报与短片。移除背景后的主体可用作版面元素。 → 互动 角色与原型可交互的角色与原型，状态保留，重新打开还在。 →
进阶

进阶功能

记忆、板书和自有密钥（BYOK）可减少重复设置。

支持修改记忆和板书以工作区文件保存，可查看和修改。

记忆 跨会话保留保留用户偏好与项目决策，新会话可继续使用。 → 板书 在画布上记录结论讨论结论保存为板书，可直接查看。 → BYOK 自有密钥（BYOK）桌面版与自部署版本支持配置 API 密钥，费用直接结算至模型服务商。 → 交付 导出与发布整站 zip、单页 HTML、.docx、PDF / PPTX，一条命令发布到公网。 → README 完整说明在 GitHub配置、本机能力、安全边界、功能状态，中英文各一份。 → 自部署 npx @xiaobuyu/nodesign全栈本地运行，需要 Node.js 22.16 以上，使用自有密钥（BYOK）或登录站点账号。 →
