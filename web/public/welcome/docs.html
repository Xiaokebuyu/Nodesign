入门

先跑通一件小事

第一次用别急着做大项目。找一件你手边的小事，一句话描述出来，看它怎么接。

不用准备注册完直接开始，线上的模型不需要配置任何东西。

桌面版装完先登录站点账号，或者在设置页填自己的密钥。下载 Windows 版。

五分钟 从一句话到第一件产物怎么描述需求，它怎么接，做完的东西落在哪。 → 画布 拖、圈、连线产物是画布上的对象：可以拖位置、圈着改、连关系。 → 计费 用量的账怎么算每一轮的 token 与金额在哪看，免费模型和付费模型怎么区分。 →
产物

同一块画布，四种产物

产物形态是画布上的一个属性。你说要什么，它就按那种产物的规范来做。

能互相取材生成图抠完直接进页面，文档里的图直接进演示。

网页 站点与落地页手写 HTML/CSS，响应式，可直接发布或整站导出。 → 文档 文档与演示真 Word 文件，排版符合中文规范；演示按屏翻页。 → 图像 图像与视频生图、抠图、海报、短片，抠出的主体可作版面元素。 → 互动 角色与原型可交互的角色与原型，状态保留，重新打开还在。 →
