01

一次描述，完成整个流程

Nodesign 将需求、制作与修改整合在同一块画布中。Agent 安排步骤、调用工具并生成产物。产物保留在画布上。

修改时可在预览上圈选区域，再输入要求。Agent 生成新版本，并保留旧版本用于回退。

初稿用于确认方向，细节可后续调整。 迭代方式

Agent 调用工具支持图像生成、背景移除、页面制作、代码执行、资料检索和截图检查。

产物保留在画布上每件产物都有固定位置，可再次查看。

对照

同一件事，两条路

左侧为传统流程，右侧为 Nodesign 流程。

保留决策权Agent 处理重复任务，用户负责判断与取舍。

02 · 一次会话的六个步骤

从需求到可交付产物

Agent 先提供结构，确认后继续制作。

①描述需求输入目标和已有信息。
②确认结构Agent 提供结构，用户确认方向。
③选择工具Agent 选择图像生成、背景移除、页面制作或代码执行工具。
④生成产物产物保留在画布上。
⑤圈选修改圈选目标区域并输入要求。
⑥保存项目各版本持续保留，支持回退。
03

一块画布，多种产物形态

Nodesign 支持多种产物形态。Agent 按对应规范生成内容。

产物支持复用图像完成背景移除后可用于页面，Word 文档中的图像可用于演示。
