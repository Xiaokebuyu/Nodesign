问

常见问题

哪个模型是免费的？

Kimi K3 那一行不计费。其它模型按实际用量折算进每天的额度，每一轮花了多少，会话栏底部当场显示。

额度用完了怎么办？

北京时间零点重置。要不受额度限制，就用桌面版填自己的密钥，或者用开源版本地跑。

能用 Claude 吗？

线上站不开放 Claude。桌面版和本地版可以：填 Anthropic 的 API 密钥，或者登录你自己的 Claude 订阅。

自带密钥支持哪些服务商？

凡是兼容 Anthropic Messages 接口或 OpenAI Chat 接口的都能填，设置页里有几家的预设。填完有体检按钮可以试。

做完的东西归谁？

归你。站点是静态文件，文档是真 Word 文件，导出之后不绑定这里。

数据存在哪？

线上站：存在服务器上你自己的工作区里，别人看不到。桌面版和本地版：存在你电脑的用户目录下，产物、板书、记忆都是普通文件。

以后会收费吗？

现在不收。线上试玩的额度可能会随成本调整。开源版按 AGPL-3.0 授权，桌面版自带密钥这条路不会加价。
