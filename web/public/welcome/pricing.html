常见问题

免费模型和别的模型有什么区别？

免费模型对所有用户开放，日常够用。要更强的模型，按用量付费，与其他模型一样按实际消耗计算。

怎么知道我花了多少？

每次会话底部写着这一轮的 token 和金额。画布上的产物还会附一条用量记录，写清这件东西的总花费。

可以自带密钥吗？

可以。填上自己的 API 密钥就能使用完整功能，费用直接走你自己的额度。适合已经有模型额度的用户。

做完的东西归谁？

归你。产物是纯静态文件，导出之后不绑定平台，放到哪里都能运行。

能商用吗？

能。你做出来的东西，版权和用途都归你。

支持哪些产物？

站点与落地页、海报与长图、演示、Word 文档、图像与视频、可互动的角色。都在同一块画布上完成。

数据存在哪？

产物和记忆都以文件形式存在你的工作区里，随时可以查看、修改和导出。
