问

常见问题

免费模型

Kimi K3 不计费。其他模型按实际用量计入每日额度，每一轮的消耗在会话栏底部实时显示。

每日额度用尽后

每日额度于北京时间零点重置。桌面版支持配置自有密钥（BYOK），也可自部署开源版本。

Claude 支持

线上版本不提供 Claude。桌面版与自部署版本支持：配置 Anthropic API 密钥，或登录 Claude 订阅。

自有密钥（BYOK）支持的服务商

兼容 Anthropic Messages 接口或 OpenAI Chat 接口的服务商均可配置，设置页内置常见预设，并提供连通性检测。

产物所有权

归用户所有。站点为静态文件，文档为标准 Word 文档，导出后不依赖本平台。

数据存储

线上版本：存储于服务器上用户各自的工作区，相互隔离。桌面版与自部署版本：存储于本机用户目录，产物、板书与记忆均为普通文件。

后续定价

当前免费。线上版本的每日额度可能随成本调整。开源版本遵循 AGPL-3.0，自有密钥（BYOK）模式不收取分成。
