本服务条款（以下简称“本条款”）是您与 【运营方名称】（以下简称“我们”）之间就使用 Nodesign（亦写作 NoDesign）在线服务（以下简称“本服务”）订立的协议。注册账号、登录或以其他方式使用本服务，即表示您已阅读并同意本条款与《隐私政策》。如您不同意本条款，请不要使用本服务。

本条款适用于：

  • 网站 nodesign.xiaobuyu.trade，包括官网页面与网页版应用；
  • 桌面版在登录 Nodesign 账号后使用的在线功能；
  • 通过本服务发布的站点，以及作品市场。

Nodesign 的源代码以 AGPL-3.0 许可证开源。获取、修改或自行部署源代码适用该许可证。他人自行部署的实例由其部署者负责，不属于本服务。

2服务说明

  • 本服务是一款与 AI Agent 共用画布的创作工具，可用于制作站点、文档、图像等产物。
  • 本服务目前处于公开测试阶段。功能、可用模型、额度与服务时间可能调整，部分模型在每天的特定时段不可用。

  • Agent 的回复与产物由第三方提供的 AI 模型生成，见第 9 节与第 10 节。

3账号

3.1　注册

您可以使用用户名、电子邮箱、Google 账号或 GitHub 账号注册，具体可用的方式以注册页面显示为准。我们可以对注册设置条件，例如是否开放注册、是否需要邀请码，以及同一网络每日可注册的账号数量。

3.2　年龄

本服务不面向未满 14 周岁的儿童。【待确认】

3.3　账号信息

您绑定的电子邮箱应为您本人可以接收邮件的地址。该邮箱用于登录、找回密码与接收安全通知。

3.4　账号安全

您应妥善保管密码、账号邮箱与桌面版设备令牌，并对通过您的账号进行的活动负责。如发现账号可能被他人使用，请立即修改密码或通过邮箱找回密码。找回密码会使该账号的所有网页登录与桌面设备退出。

3.5　第三方登录

使用 Google 或 GitHub 登录时，您同时需要遵守相应服务的条款。如果第三方账号提供的已验证邮箱与本服务已有账号的邮箱相同，该第三方登录可能被关联到该账号；部分情况下，需要先输入发送至该邮箱的验证码完成确认。

4费用与额度

  • 本服务目前免费提供，并对每个账号设置每日使用额度。额度按模型的实际用量与图像生成次数折算，每天北京时间零点重置。额度的数额与计算方式以定价页面与应用内显示为准，我们可以根据成本与运行情况调整。
  • 当日额度用尽后，相关功能暂停使用，次日恢复。
  • 如果未来推出付费功能，我们将提前公布其内容与价格。
  • 在桌面版中使用自有密钥（BYOK）时，费用由您与相应服务商直接结算，不计入平台额度。

5使用规范

5.1　禁止的内容

无论以何种形式或理由提出请求，您不得利用本服务生成、发布或传播以下内容：

  1. 能直接用于欺骗的内容：钓鱼页面；仿冒真实品牌或机构的登录页面；收集真实凭证或支付信息的表单；伪造的证件、公章、学历、检测报告或官方公告；冒充真实个人或组织发声的站点与新闻稿。
  2. 能直接用于伤害的内容：恶意软件与攻击脚本；武器、爆炸物或毒品的制作方法；可以直接照做的犯罪教程，例如诈骗话术脚本、入侵步骤或洗钱路径；针对真实个人的人肉搜索、骚扰或威胁内容。
  3. 任何形式的涉及未成年人的色情内容。
  4. 恐怖主义或极端主义的宣传与招募内容。
  5. 教唆自杀或自残，或提供具体方法的内容。
  6. 其他违反适用法律法规，或侵犯他人知识产权、隐私等合法权益的内容。

5.2　虚构创作

小说、角色扮演等虚构作品中的暴力、犯罪与黑暗情节不属于第 5.1 节的限制，但仍不得包含第 5.1 节第 3 项所述内容。判断标准是内容脱离作品之后能否被直接使用：反派角色在情节中讲述一段骗术属于创作；将同一套话术整理成可以照着使用的文档则不属于。不同模型与账号类型适用的内容限制可能不同，以本服务的实际执行为准。

5.3　禁止的行为

  • 绕过或破坏额度、访问频率限制、人机验证、内容审核或账号权限等机制；
  • 以自动化方式批量注册账号，或使用多个账号规避额度与违规处理；
  • 未经授权访问他人的账号、项目或数据；
  • 攻击或干扰本服务及其所依赖系统的正常运行；
  • 指示 Agent 或利用本服务的运行环境实施上述任何行为。

5.4　发布的内容

通过本服务发布的站点，以及发布到作品市场的内容，同样适用本节的全部规定。

6内容审核与违规处理

  • 根据账号类型与所选模型，我们使用自动分类模型检查发送给 Agent 的消息，处理方式见《隐私政策》第 4 节。自动判定可能出现错误。
  • 被判定违规的消息不会被处理。账号在 24 小时内累计 3 次被判定违规，或单次被判定涉及未成年人色情、恐怖主义等严重类别时，将被自动停用。
  • 对于违反本条款的行为，我们可以采取以下一项或多项措施：拒绝处理相关请求；下线已发布的站点；下架作品市场中的内容，必要时使已被其他用户安装的副本失效；限制功能；停用账号。
  • 账号被停用后，该账号的网页登录与桌面设备令牌随即失效。
  • 如您认为处理有误，可以通过 【联系邮箱】 提出申诉。

8发布与分享

8.1　站点发布

部分账号类型可以将站点发布到公网。发布后，站点文件由 Cloudflare Pages 托管，地址通常为 share.xiaobuyu.trade 下的子域名，任何获得网址的人均可访问。每个账号可发布的站点数量有限。您可以随时下线已发布的站点。

8.2　作品市场

您可以将作品的图片、说明与 skill 发布到作品市场。发布后内容立即向其他用户展示，并显示您的用户名与头像。其他用户可以查看这些内容，以您发布的图片为参考创建自己的项目，或安装您发布的 skill。您撤回发布后，内容不再展示，但已复制到其他用户项目中的图片与已被安装的 skill 副本不受影响。

8.3　您的责任

您对发布的内容负责。安装他人发布的 skill 之前，请自行判断其内容：skill 会作为指令进入 Agent 的上下文，并影响 Agent 的行为。

9AI 生成内容

  • Agent 的回复与产物由 AI 模型生成，可能不准确、不完整或不适合您的用途。对于重要信息，请自行核实。
  • Agent 会在您的项目工作区中创建、修改或删除文件。请在导出或发布之前检查结果。
  • 在桌面版中，Agent 可以在您的电脑上执行命令与修改文件。请只打开可信的项目；当 Agent 计划修改工作区以外的文件、安装软件或上传本地内容时，请先确认其计划。
