关于

Nodesign 将构思、制作与修改整合到一块画布

创作工具持续发展，工作流程也分散在多个软件中。构思、制作与修改往往需要切换不同工具。

Nodesign 将这些环节整合在同一块画布中，并让这块画布同时服务于用户与 Agent。用户在画布上指定、整理与修改，Agent 在画布上制作、检查与说明。产物保留在画布上，支持圈选、修改和添加关系线。

原则

我们相信的三件事

产品原则这三项原则用于指导产品决策。

01

产物归用户

产物以标准文件格式导出。站点为静态文件，文档为 Word 文档。离开平台后仍可打开和编辑。

02

过程透明

会话栏逐条记录 Agent 调用的工具、文件改动和费用。每轮费用直接显示。

03

决策权归用户

Agent 处理排版、生成、导出和对齐。用户负责审美判断与内容取舍。

边界

我们不做的几件事

×封闭格式我们不采用仅能通过 Nodesign 打开的产物格式。
×替用户决定审美我们不预设单一风格。关键信息缺失时，Agent 会先确认。
×隐藏用量我们在每轮会话中显示 token 与金额。
